CASE FILE 02 / 빛의 단서

달은 빛을 만들지 않아요.
태양빛을 반사하죠.

태양은 달의 한쪽 절반을 비춥니다. 달이 공전하면 지구에서 보이는 밝은 부분의 비율이 바뀝니다.

관찰 01 · 어디에서 빛이 올까?
태양빛의 방향 →
🔍 조사 기록

달의 어두운 부분은 항상 지구 그림자일까요?

아니에요. 달에는 태양빛을 받는 낮과 받지 않는 밤이 있어요. 지구에서 달의 밤 부분을 바라보면 어둡게 보일 수 있죠.

기억할 것
일반적인 달의 위상 변화는 지구 그림자 때문이 아닙니다.

CASE FILE 04 / 특별한 정렬

그럼 월식은 언제 일어날까?

같은 달의 공전 궤도에서 조사합니다. 황도면과 백도면이 약 5.1° 기울어져 있어, 보름달도 지구 그림자를 비켜갈 수 있어요.

관찰 03 · 같은 궤도, 다른 현상
같은 달의 공전 궤도본그림자반그림자
🔍 그림자 수사 결과
현재 관측 결과개기월식

달이 지구 본그림자 안으로 들어왔습니다.

삭보름 위치삭
교점이 보름 방향교점이 직각 방향
핵심 증거 황도면(지구의 공전 궤도면)과 백도면(달의 공전 궤도면)은 약 5.1° 기울어져 있습니다. 교점 근처에서 보름달이 지구 그림자를 통과하면 월식이 일어납니다.
반그림자월식: 태양빛 일부만 가려져 달이 미세하게 어두워집니다.
부분월식: 달 일부가 본그림자 안으로 들어갑니다.
개기월식: 달 전체가 본그림자 안에 들어갑니다.
※ 이해를 돕기 위해 궤도 기울기와 그림자 크기는 실제보다 크게 그렸습니다.
CASE FILE 05 / 두 사건 비교

원인은 다르지만,
둘 다 달의 모양을 바꿔 보여요.

두 현상을 한눈에 비교해 보세요. 위상은 밝은 면을 보는 각도, 월식은 지구 그림자 통과 여부가 핵심입니다. 반그림자도 함께 구별해 보세요.

🌙 평소의 달의 위상 변화

원인: 태양빛을 받은 면을 지구에서 보는 방향이 달라짐
시기: 약 29.5일마다 한 주기
지구 그림자: 필요 없음

🌘 특별한 날의 월식

원인: 달이 지구의 반그림자 또는 본그림자에 들어감
종류: 반그림자월식 · 부분월식 · 개기월식
시기: 보름달 무렵, 궤도 정렬 조건이 맞을 때
지구 그림자: 현상의 직접적인 원인

🕵️ 증거 분류 미션 제한 시간 없음 · 틀려도 다시 선택 가능

다음 상황은 달의 위상 변화일까요, 월식일까요? 증거를 하나씩 선택해 보세요.

증거 ①

한 달 동안 초승달이 상현달과 보름달로 변했다.

증거 ②

보름달이 지구의 본그림자에 일부 들어가 어두워졌다.

증거 ③

보름달이 지구의 반그림자를 지나면서 약간 어두워졌다.

🔎 밝혀낸 증거 0 / 3

* 궤도, 거리, 크기와 그림자 범위는 개념 이해를 위해 단순화한 모식도입니다. 실제 태양·지구·달의 크기 및 거리는 비례하지 않습니다.
